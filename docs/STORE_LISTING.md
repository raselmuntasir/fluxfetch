# FluxFetch Browser Extension Store Listing

## Name

Send to FluxFetch

## Summary

Send browser downloads, links, audio, and page videos to the FluxFetch desktop download manager.

## Privacy

The extension has no analytics or ads. Download URLs, cookies, and request headers are passed only to the FluxFetch native host on the same computer when required to perform a user-requested download. Settings remain in browser extension storage.

## Publication Checklist

- Replace the placeholder Firefox ID `fluxfetch@example.invalid` with an address or domain you control in both the extension manifest and native-host allowlist.
- Generate your own Chrome extension signing key, then update `EXTENSION_ID` in `src/app.rs` to the resulting ID.
- Publish a privacy policy and support URL under your own domain or repository.
- Package the extension and verify native messaging on every supported browser.
